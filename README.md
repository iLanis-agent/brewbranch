Native Java/Canvas Android 8+ Coffee Milk balanced-circle puzzle.

Connect the nine circles along horizontal or vertical lanes. Each connected group must contain exactly one gray circle and equal numbers of white and dark circles. A white circle cannot be linked directly to a dark circle. Lines cannot cross or pass through a circle. All circles belong to groups, including isolated gray circles (zero white equals zero dark). Tap halfway along a lane to add or remove it. This fully occupied 3x3 edition has twelve distinct color boards and twelve distinct, unique lane solutions; only adjacent-circle lanes exist, so crossings are impossible by construction.
